Обновление версии мода

Маркер версий, который читает UpdateChecker внутри мода. Сам мод качается не отсюда — здесь только объявление новой версии.

A = Alpha, B = Beta, без буквы = релиз. Сравнение: сначала числа, потом канал (A < B < релиз). Пример: B0.2.1 покажется как «0.2.1 Beta». 


  
Порядок обновления

  
    
    
  1. Подними версию самого мода в gradle.properties / MCreator (например, 0.2.1), собери jar.
    2. 
    
  2. Опубликуй jar там, где раздаёшь мод, и вставь ссылку в поле «url».
    3. 
    
  3. Нажми «Сформировать update.json», скопируй JSON.
    4. 
    
  4. Нажми «Открыть update.json на GitHub», замени содержимое и закоммить в main.
    5. 
    
  5. Через ~1 минуту Pages и raw-файл обновятся. Игрок увидит сообщение при следующем входе.
    6. 
  

  
Важно: если версия в jar осталась 1.0.0, а в update.json B0.2.1 (числа 0.2.1), обновление не покажется — 0.2.1 меньше 1.0.0.
